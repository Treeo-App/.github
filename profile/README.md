# Treeo

**El cliente de escritorio para Firebase Firestore.**

Treeo es una app nativa de macOS para explorar, editar y consultar Firestore sin salir del escritorio, con todo el procesamiento en local.

Sitio web y documentación: [treeo.app](https://treeo.app) y [treeo.app/docs](https://treeo.app/docs)

Los repositorios de código de Treeo son privados. Para reportar un problema de seguridad, consulta nuestra política en [SECURITY.md](https://github.com/Treeo-App/.github/blob/main/SECURITY.md).
